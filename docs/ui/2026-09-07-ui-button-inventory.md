## 非 button 控件与覆盖边界

| 对象 | 设计合同 |
| --- | --- |
| input / textarea | 常驻字段名，单行最小 40px；错误就地说明；失败保留输入；不以 placeholder 代标签 |
| select / 枚举 | 中文展示值与 canonical 枚举分离；不手填技术 ID；未选项有占位 |
| checkbox / radio | 标签整行可点击，热区 ≥32px；键盘可用、可访问名称明确 |
| details / summary | 收纳进阶信息；不得把主流程阻塞藏在折叠区；展开状态可见 |
| tab / 分段 | 选中与焦点分离；采用 tab role 时补齐 panel 关联与方向键行为 |
| 拖动分隔条 | 支持拖动与键盘步进；窄窗变抽屉或选择器后内容仍可达 |
| 正文编辑 | 支持中文输入法，组合输入不触发快捷保存；18px 正文与持续保存状态 |
| 系统文件对话框 | 保留 Main 授权文件选择；不改为 Renderer 任意路径输入 |
| 新增纯 UI 控件 | 更多菜单、导航开关、抽屉关闭、格式选项按同一规格；正式切片补录 |

[机器可读记录](./2026-09-07-ui-buttons.json) 包含源码、DOM 锚点、原禁用条件、目标文案、类型、位置、状态和可达性备注，用于后续逐项认领。
